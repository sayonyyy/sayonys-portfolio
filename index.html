My Projects

Gett Ride Failure Analysis

Conducted a product analytics investigation on ride failure records from the Gett ride-hailing platform (similar to Uber and Lyft) using SQL and Python. Analyzed driver assignment delays, ETA distributions, demand spikes, and rider cancellation behavior while mapping geographic failure hotspots using H3 hexagonal spatial clustering. Identified peak failure periods at 8 AM and 9–11 PM with ~70–75% of failures occurring before driver assignment, revealing a supply–demand imbalance. Proposed operational improvements including driver incentives during peak hours, improved dispatch algorithms, and dynamic driver positioning in high-demand zones to reduce ride cancellations.

DoorDash Delivery Duration Prediction

Developed an end-to-end machine learning pipeline to predict food delivery duration using a dataset of 177K+ DoorDash orders. Engineered operational features such as driver supply ratios, order complexity indicators, and marketplace congestion metrics, applying one-hot encoding and multicollinearity filtering for feature preparation. Trained and evaluated Linear Regression, Random Forest, XGBoost, and LightGBM models using RMSE and MAE, with tuned LightGBM achieving the best performance (~17.09 RMSE). Conducted hyperparameter tuning, feature importance analysis, and ETA simulation to demonstrate real-time delivery prediction capabilities.

Interpretable Retail Demand Forecasting

Developed a complete time-series retail demand forecasting system using statistical and machine-learning models on weekly Walmart-style sales data. Converted raw time-series data into a supervised ML format by engineering lag features, rolling averages, and seasonal indicators. Evaluated Naive, Linear Regression, Random Forest, XGBoost, and ARIMA/SARIMA models using RMSE, MAE, and MAPE — with XGBoost delivering the best predictive performance.  Applied SHAP interpretability to explain model behavior, highlighting strong short-term autocorrelation and seasonal demand patterns, enabling actionable inventory insights.

Developed a forecasting model for international trade using historical data from the UN Comtrade database. The project applies two approaches — Linear Regression to capture long-term trade trends, and ARIMA (AutoRegressive Integrated Moving Average) to account for time-dependent patterns and seasonal fluctuations. Patternova: ML-Driven Kolam Creation Backend

Built an advanced ML backend for Patternova that analyzes and generates intricate Kolam patterns from dot inputs. The system combines traditional dot detection using OpenCV with a synthetic dataset generator for model training, alongside a U-Net image-to-image model (dots → Kolam strokes) implemented in PyTorch. A complete training and inference pipeline ensures efficient processing, while postprocessing converts outputs into skeletonized images and vectorized SVGs. Additional features include data augmentation, automatic grid alignment, and smooth, continuous stroke generation via recursive Bezier-like curves.
